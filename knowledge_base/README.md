# Evidence Bridge knowledge base

Uploaded PDFs and their page-level JSON extraction caches persist in this directory.
You can upload PDFs through Evidence Bridge or place a text-based PDF here; the next
scan indexes it. PDF and cache files are excluded from version control.

Only real PDF files in this directory appear in Active Knowledge Base and enter
Evidence Bridge or Evidence & Guidance retrieval. There are no bundled guideline
summaries. Upload an original guideline PDF to cite its exact extracted passages
by physical PDF page number.

Scanned/image-only documents require OCR before ingestion. Password-protected
PDFs must be unlocked before uploading. The workspace reports these conditions
instead of substituting invented document text.
